# Portfolio Website

This is a personal portfolio website built with HTML, CSS, and JavaScript.

## Features
- Modern, responsive design
- About, Projects, and Contact sections
- Interactive contact form

## Usage
Open `index.html` in your browser to view the portfolio.

## Customization
- Update the content in `index.html` to personalize your information and projects.
- Modify `style.css` for custom styles.
- Enhance interactivity in `script.js` as needed.
